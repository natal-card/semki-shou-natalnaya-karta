# Как попасть на съёмки «Натальной карты»

Проверьте [афишу продакшена Medium Quality](https://mediumquality.ru/natalnayakarta). Сеансы зависят от конкретной записи. В официальном объявлении должны совпадать город, площадка, дата и время.

## Перед покупкой

1. Найдите сеанс на официальной странице проекта.
2. Проверьте время сбора, адрес и возрастное ограничение в карточке сеанса.
3. Уточните, какие документы нужны на входе и на чьё имя выписывается билет.
4. Сохраните правила обмена и возврата из текущей афиши.

Если сеансов нет, ориентируйтесь на новые объявления продакшена. Дата съёмки и дата выхода видео — разные события. Для зрителя онлайн действует [архив выпусков](https://nk-vkvideo.ru/episodes).

Памятка сверена с официальной страницей 10 ноября 2026 года. [Справка независимого фан-архива о съёмках](https://nk-vkvideo.ru/tickets?utm_source=github&utm_medium=referral&utm_campaign=natalcard_readme_pilot&utm_content=semki-shou-natalnaya-karta).
